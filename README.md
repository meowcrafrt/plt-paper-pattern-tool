# PLT 紙樣排版工具網站

這是一個純靜態網站；PLT 檔案由學員的瀏覽器在本機解析，不會上傳到網站。

## 上線方式

將此資料夾內所有檔案完整上傳到任一靜態網站主機，例如 GitHub Pages、Cloudflare Pages、Netlify 或你的課程網站空間。學員開啟 `index.html` 對應的網址後，按「開啟紙樣工具」即可使用。

不要只上傳 `index.html`：`tool.html`、`manifest.webmanifest` 與 `service-worker.js` 必須一併上傳並維持同一層資料夾。

## 紙樣安全原則

- 拆圖排版固定 100%（1:1），不會自行縮放。
- 每頁都有 100 mm 校正尺；學員必須先以實體尺量測確認。
- 列印時必須在系統列印視窗關閉「符合頁面」等自動縮放。
